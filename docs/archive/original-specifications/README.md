# Original specifications (historical)

These three documents specified the 2025–2026 internship version of OptiEDT for one
department of a Tunisian public faculty. They are kept as domain evidence — the LMD
structure (CM/TD/TP), six-day weeks, closed half-days, Ramadan timing and lunar holidays —
not as requirements of the current product. The current requirements are in
`docs/product/requirements.md`.
